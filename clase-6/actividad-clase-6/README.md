# Actividad · Cartelera de recomendaciones

Desarrollar una aplicación que administre una colección de recomendaciones.

## Requisitos indispensables

1. Mantener un array con al menos tres recomendaciones iniciales.
2. Recorrerlo con `forEach()` y una función flecha o con un `for`
3. Crear una tarjeta de Materialize por cada elemento. (https://materializecss.com/cards.html)
4. Mostrar la cantidad mediante `length`.
5. Agregar elementos desde el formulario con `push()`.
6. Impedir que se agreguen textos vacíos.
7. Eliminar el último elemento con `pop()`.
8. Actualizar la interfaz después de cada modificación.

## Desafíos opcionales

- Evitar recomendaciones repetidas utilizando `includes()`.
- Mostrar un mensaje cuando la colección esté vacía.
- Cambiar la variante de color de las tarjetas según su posición.
- Agregar un botón que vacíe toda la cartelera.
