# Actividad — Calculadora de descuento

Desarrollar una aplicación que determine el tipo de entrada que le corresponde a una persona según su edad.

La aplicación deberá:

1. Obtener el nombre y la edad ingresados.
2. Convertir la edad a número.
3. Validar que el nombre no esté vacío y que la edad sea mayor que cero.
4. Mostrar un mensaje de error cuando los datos no sean válidos.
5. Crear una función que reciba el nombre y la edad.
6. Usar `if`, `else if` y `else` para decidir el tipo de entrada.
7. Mostrar el resultado dentro de la página.

## Condiciones

- Menos de 18 años: descuento para menores.
- Entre 18 y 64 años: entrada general.
- 65 años o más: descuento para jubilados.

## Desafío opcional

Agregar una casilla que permita indicar si la persona es estudiante y mostrar un descuento especial cuando sea mayor de edad y estudiante.
